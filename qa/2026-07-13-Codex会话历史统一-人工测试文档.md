## 回归关注

- 不应清空 `auth.json` 中的官方登录材料。
- 不应把未知外部 provider id 粗暴迁入 `tuziswitch`，迁移源必须来自本机 tuzi-switch Codex provider 配置。
- 不应重复迁移已统一的 state DB。
- 不应在关闭统一历史时把所有 `tuziswitch` 会话粗暴改回 `openai`，只能按备份账本恢复官方会话。
- state DB 备份必须在改写前完成，且要保留 `sqlite/` 子目录路径，避免两个 `state_5.sqlite` 备份互相覆盖。
