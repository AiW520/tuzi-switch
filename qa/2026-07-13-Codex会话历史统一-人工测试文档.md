# 2026-07-13 Codex 应用增强默认开启人工测试文档

## 测试范围

- 本次后续修改只覆盖设置页通用页签中的两个 Codex 应用增强开关：
  - 切换第三方时保留官方登录
  - 统一 Codex 会话历史
- 应用启动时默认开启。
- 同一次运行内手动关闭后，刷新设置页仍保持关闭。
- 完全退出应用后重启，恢复默认开启。

3. 运行期状态验证：同一次应用运行内，手动关闭后刷新设置页仍保持关闭。
4. 重启状态验证：完全退出应用后重新启动，两个开关恢复开启。

## 建议人工验证

1. 清空或删除两个 Codex 应用增强字段后打开设置页，确认两个开关默认开启。
2. 手动关闭两个开关并保存，刷新设置页后确认仍为关闭。
3. 完全退出 `tuzi-switch` 后重新启动，确认两个开关恢复开启。
4. 再次手动关闭后手动开启，确认开关可正常操作。

## 回归关注

- 不应在同一次运行内把用户手动关闭后的 `false` 立即兜底成开启。
- 不应把关闭状态持久落盘到下一次启动。
- 不应影响“迁入既有官方会话仍需手动确认”的弹窗逻辑。
